# STAGE 1 — MULAI

## 👋 Selamat Datang

Selamat datang di KLAS! Di kelas ini kamu akan belajar membangun software bersama Claude Code, asisten coding berbasis AI yang bekerja langsung di terminal kamu.

Cara belajar di sini sederhana: **baca materi → praktik → tandai selesai**. Tekan tombol **Tandai selesai** di kanan atas setiap materi untuk mencatat progresmu.

> Materi ini adalah contoh awal. Ganti isi folder `content/` dengan materi buatanmu sendiri.

## 📥 Install Claude Code

Claude Code membutuhkan Node.js 18 atau lebih baru. Setelah itu jalankan:

```bash
npm install -g @anthropic-ai/claude-code
```

Cek instalasi dengan `claude --version`.

## 💻 Sesi Pertama

Masuk ke folder proyek lalu jalankan `claude`. Coba minta sesuatu yang sederhana:

```
Jelaskan struktur folder proyek ini
```

Claude akan membaca file-file di proyekmu sebelum menjawab. Perhatikan bagaimana ia meminta izin sebelum mengubah file.

## ✅ Tugas

1. Install Claude Code.
2. Buka satu proyek (atau folder kosong) dan jalankan `claude`.
3. Minta Claude membuat file `hello.txt` berisi namamu.
