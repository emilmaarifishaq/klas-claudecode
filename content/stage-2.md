# STAGE 2 — MEMORI PROYEK

## 🧠 Apa Itu CLAUDE.md

`CLAUDE.md` adalah file di root proyek yang otomatis dibaca Claude Code setiap sesi. Isinya adalah hal-hal yang ingin kamu ingatkan terus: cara menjalankan proyek, gaya kode, dan aturan penting.

## 📄 Membuat CLAUDE.md Pertama

Jalankan `/init` di dalam Claude Code untuk membuat draf otomatis, lalu rapikan. Contoh isi yang baik:

```markdown
# Proyek Toko Online
- Jalankan dev server: npm run dev
- Tes: npm test (wajib hijau sebelum commit)
- Gunakan TypeScript strict, jangan pakai any
```

## ✂️ Tetap Singkat

CLAUDE.md yang terlalu panjang justru mengurangi fokus. Tulis hanya aturan yang benar-benar sering dilanggar atau tidak bisa ditebak dari kode.

## ✅ Tugas

Buat CLAUDE.md untuk proyekmu dengan maksimal 10 baris, lalu minta Claude menjelaskan kembali aturan proyekmu.
