# STAGE 2 — MEMORY

## ▶️ STAGE 2 — Start Here

![Stage 2 — Memory](/images/stage2-never-forgets.png)

Claude Code is installed (Phase 1). One problem remains: every new session it starts as a blank slate — you'd re-explain your business, your goals, and how you like to work, every single time. This phase fixes that **permanently**.

### Why this phase comes before the fun stuff

You could skip straight to building websites — and you'd get worse output every session for the rest of the course. **Memory is the multiplier on every other stage.** A Claude that already knows your voice, your stack, and your "definition of done" doesn't need you to re-explain yourself before each build — so every later lesson lands sharper, faster, cheaper. Ten minutes here saves ten hours later. That's the trade.

### What you'll walk away with

- **Claude set up to remember you** — your name, your business, how you work — automatically, at the start of every chat.
- A set of **memory files** (CLAUDE.md, SOUL.md, DESIGN.md, VOICE.md, AUDIENCE.md) that feed Claude everything it needs to work like it already knows you.

## 💛 File 2 — SOUL.md (Who You Are)

> **You'll walk away with:** a SOUL.md file that captures the human behind the work — your story, your beliefs, your why — so Claude can sound like you, not like everyone. Claude interviews you and writes it for you.

This isn't your résumé — it's *you*. Your origin, the moment things changed, the opinions you actually hold. Claude pulls from this whenever it writes in your voice, tells your story, or makes a judgment call that should reflect your values.

You don't write it from a blank page. **Claude interviews you** — one question at a time — then writes the file from your answers.

### Set it up (in the desktop app)

Open the Claude Code panel and paste the prompt below. Answer the 7 questions honestly (short is fine). When you're done, Claude writes and saves your SOUL.md.

**Prompt:**

> I want to build my soul.md file — the document that tells you who I am at a human level. Interview me with 7 questions, one at a time. Ask about: my origin story, the moment I decided to change direction, what I actually believe about [my industry], what I'm optimistic about, what I'm done pretending is true, what I'd tell my earlier self, and what I'm building toward. After I answer all 7, write and save my soul.md.

## 🗣️ File 4 — VOICE.md (How You Talk)

> **You'll walk away with:** a VOICE.md file with your tone, your phrases, and the words you never use — so every caption, post, email, and DM Claude writes actually sounds like you.

This is where Claude learns *how you talk* — not a generic brand-voice doc, but your specific rules.

**Prompt:**

> Create my voice.md file. Follow these steps in order.
> Step 1 — Mine what you already know. Look at everything I've written in this conversation. Pull out patterns: sentence length, energy level, words I reach for, words I avoid.
> Step 2 — Ask me 3 questions to fill the gaps.
> Step 3 — Write and save voice.md with: my tone in 3 words, 5 "I always say" phrases, 5 "I never say" words, and 3 example lines in my voice.

## 🎯 15 Proven Memory Prompts

These are **15 proven prompts** for Memory. Copy any one, fill in the **[BRACKETS]**, and send.

**1. Build a Lean CLAUDE.md**

> Help me create a CLAUDE.md file for this project. Ask me clarifying questions first, then keep the file lean — under 150-200 lines. Structure it as the WHAT (tech stack, project structure, build commands), the WHY (purpose of each part), and the HOW (how I want you to work). It's read on every single message, so every line must earn its place — no history, no filler.

**2. CLAUDE.md as an Index, Not a Dump**

> My CLAUDE.md is getting too long and slowing Claude down. Restructure it as a lean index: core rules stay in CLAUDE.md (under 50 lines), everything else (persona, audience, stack details) moves into separate files that CLAUDE.md references by name. Keep it tight — every line is a token cost.

**3. Auto-Update Memory After Each Session**

> At the end of every working session, remind me to run this: "Review our conversation and update my memory files with anything new — new decisions, new constraints, new preferences, new project state. Keep each file lean."

## ♻️ Keep Your Memory Alive (The Update Habit)

> **You'll walk away with:** the one habit that keeps your memory from going stale — so 'never re-explain yourself again' is still true three weeks from now.

The habit is dead simple: **when something changes, just tell Claude to remember it.**

### Capture facts the moment they happen

Picked a new niche? Changed what you're building? Decided how you like something done? Tell Claude right then, in plain words:

> **"Remember this for next time: [the fact]."**

Claude updates your memory itself — you don't open anything or touch a file. Next session, it already knows.

### Keep it short

Adding is not hoarding. A bloated memory actually makes Claude *worse*, not better. So the habit is: **add one line, delete one line** — keep your total file length roughly constant.
