## ⚡ Quick Install

```bash
# Clone the kit
git clone https://github.com/claudecodeclub/ultimate-kit.git ~/claude-kit

# Copy global config
cp ~/claude-kit/global/* ~/.claude/

# Install all skills
cp ~/claude-kit/skills/* ~/.claude/skills/

# Copy agent configs
cp ~/claude-kit/agents/* ~/.claude/agents/

# Initialize memory layer
cp ~/claude-kit/memory/* ~/.claude/memory/
```

After installing, open Claude Code and verify with:
```
Read ~/.claude/CLAUDE.md and confirm you can see my configuration.
Then run /plan to confirm skills are loading.
```

## 🔧 Customizing The Kit

The kit is a starting point, not a finished product. Everything should be customized to your context.

**Priority customizations:**

1. **Global CLAUDE.md** — replace all placeholder text with your actual details. The kit's template is a structure; your content is what makes it work.

2. **Voice section** — add 3 examples of your actual writing. This is what makes Claude sound like you instead of a generic AI.

3. **Stack section** — update with the actual tools, languages, and platforms you use. Wrong stack info is worse than no stack info.

4. **Rules section** — the kit includes sensible defaults, but add rules based on your specific workflow. Every rule you add is one instruction you never have to repeat.

5. **Skills** — remove skills you won't use. A shorter, relevant skill list is better than a comprehensive one you ignore.
