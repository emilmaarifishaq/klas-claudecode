# BONUS — TIPS HARIAN

## ⌨️ Perintah Garis Miring

Ketik `/` di Claude Code untuk melihat semua perintah. Yang paling sering dipakai: `/clear` untuk memulai konteks baru dan `/init` untuk membuat CLAUDE.md.

## 🐛 Saat Ada Error

Tempel pesan error lengkap ke Claude, bukan ringkasannya. Semakin lengkap konteks, semakin cepat masalah ketemu.
