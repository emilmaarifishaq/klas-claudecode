# STAGE 3 — PROYEK PERTAMA

## 🎯 Pilih Proyek Kecil

Proyek pertama sebaiknya bisa selesai dalam satu sore. Contoh: aplikasi daftar belanja, kalkulator zakat, atau halaman portofolio.

## 📋 Rencanakan Dulu

Tekan **Shift+Tab** untuk masuk ke Plan Mode. Jelaskan tujuanmu, lalu minta Claude menyusun rencana langkah demi langkah sebelum menulis kode. Koreksi rencananya jika ada yang kurang pas.

## 🔨 Bangun Bertahap

Kerjakan satu fitur per langkah. Setelah tiap fitur berjalan, commit dengan git supaya kamu selalu punya titik aman untuk kembali.

## ✅ Tugas

Selesaikan satu aplikasi kecil dan deploy ke Vercel.
